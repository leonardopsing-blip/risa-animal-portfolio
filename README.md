# RisAnimal — sitio independiente

Portafolio autónomo de Emily Peñafiel / RisAnimal. No comparte código, ruta, dominio ni despliegue con el sitio de LPS.

## Vista local

Ejecuta `node serve.mjs` dentro de este directorio y abre `http://localhost:4174`.

## Fuentes

Las obras enlazan al blog público de RisAnimal y los casos de estudio a los perfiles originales proporcionados. Los cuatro archivos de obra se alojan mediante URLs públicas independientes.
